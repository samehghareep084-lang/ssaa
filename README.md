# سكساوي | Seksawy

منصة فيديوهات ثابتة مناسبة للنشر على GitHub Pages. الزوار يشاهدون الفيديوهات ويتفاعلون معها ويكتبون التعليقات ويشاركون روابطها. لا يوجد رفع فيديوهات من المستخدمين في هذه النسخة.

## تشغيل سريع

1. ارفع كل ملفات المجلد إلى مستودع GitHub.
2. من إعدادات المستودع افتح **Settings → Pages**.
3. اختر **Deploy from a branch** ثم `main` و`/(root)` واحفظ.
4. انتظر نشر الموقع وافتح رابط GitHub Pages.

ستظهر الصفحة ببيانات تجريبية. لتشغيل فيديو فعلي، عدّل `videos.js` وأضف رابط MP4 مباشر في الخاصية `video` ورابط صورة في `image`.

## تفعيل التعليقات والإعجابات (Supabase المجاني)

1. أنشئ مشروعاً في Supabase.
2. افتح **SQL Editor** وشغّل محتوى `supabase.sql`.
3. من **Project Settings → API** انسخ Project URL و`anon` / publishable public key.
4. افتح `config.js` وضع القيم مكان النصوص الفارغة.
5. ارفع التعديل إلى GitHub.

**مهم:** استخدم المفتاح العام anon/publishable فقط مع سياسات RLS الموجودة. ممنوع وضع `service_role` أو أي مفتاح سري في ملفات GitHub.

## إضافة فيديو

افتح `videos.js` وأضف عنصراً جديداً داخل المصفوفة، مثال:

```js
{
  id: "lesson-01",
  title: "عنوان الفيديو",
  description: "وصف مختصر للفيديو",
  category: "تعليم",
  channel: "سكساوي",
  views: "جديد",
  duration: "08:20",
  image: "https://example.com/thumbnail.jpg",
  video: "https://example.com/video.mp4"
}
```

- `id` لازم يكون فريداً، ويفضل استخدام حروف إنجليزية وأرقام وشرطة.
- `video` لازم يكون رابط ملف فيديو مباشر يدعم المتصفح، مثل MP4. رابط صفحة يوتيوب العادي ليس رابط MP4 ولن يعمل في مشغل HTML5.
- ارفع الفيديو على خدمة تسمح بالربط المباشر والتضمين، وتأكد من شروطها وحدودها المجانية.

## حدود النسخة الحالية

- GitHub Pages يستضيف ملفات الواجهة فقط، ولا يشغّل Flask أو قاعدة بيانات.
- الفيديوهات نفسها مستضافة خارج GitHub Pages.
- Supabase يحفظ التعليقات والإعجابات، وتوجد حدود استخدام للخطة المجانية.
- التفاعل الحالي يعتمد على معرّف زائر محفوظ في المتصفح؛ ليس نظام حسابات أو حماية قوية ضد التصويت المتكرر من أجهزة/متصفحات مختلفة. التعليقات عامة ويمكن لأي زائر نشرها، لذلك راجعها واحذف المسيء من لوحة Supabase.
- لا توجد لوحة إدارة داخل الموقع حالياً؛ أنت تضيف الفيديوهات بتعديل `videos.js`.
